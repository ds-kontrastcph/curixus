# 02-conventions.md

## Coding Conventions

All conventions documented here are **actively used** in this codebase. Follow these patterns when adding new code.

## Naming Conventions

### File & Directory Naming

#### WordPress Templates
- **Pattern**: `lowercase-with-hyphens.php`
- Examples: `header.php`, `footer.php`, `page.php`, `single.php`, `content-page.php`
- Template parts: `template-parts/content-{type}.php`
- Page templates: `page-templates/{name}.php`

#### PHP Include Files
- **Location**: `/inc/`
- **Pattern**: `lowercase-with-hyphens.php`
- Examples: `template-functions.php`, `custom-header.php`, `init-cpt.php`

#### Custom Post Type Files
- **Location**: `/inc/post-types/`
- **Pattern**: `{singular-cpt-name}.php`
- Example: `modals.php`

#### Blocks
- **Location**: `/blocks/{block-slug}/`
- **Pattern**: Block slug uses hyphens, matches block.json name
- Examples: `button-group/`, `card-tiles/`
- Required files: `block.json`, `block-render.php`, `style.scss`

#### SCSS Files
- **Pattern**: `_partial-name.scss` (partials start with underscore)
- **Main file**: `style.scss` (no underscore, imports partials)
- Examples: `_variable.scss`, `_components.scss`, `_header.scss`

#### JavaScript Files
- **Pattern**: `kebab-case.js` or `jquery.name.js`
- Examples: `jquery.main.js`, `background-sections.js`, `block-styles.js`

### PHP Naming

#### Functions
- **Pattern**: `{theme_prefix}_{descriptive_name}`
- **Theme prefix**: `curixus_project_`
- Examples:
  ```php
  curixus_project_setup()
  curixus_project_scripts()
  curixus_project_body_classes()
  ```
- **Helper functions** (no prefix required if unique):
  ```php
  sprite_svg()
  get_excerpt_trim()
  extract_youtube_id()
  ```

#### Classes
- **Pattern**: `PascalCase_With_Underscores` (WordPress convention)
- Examples:
  ```php
  class Header_Menu_Walker extends Walker_Nav_Menu {}
  class Footer_Menu_Walker extends Walker_Nav_Menu {}
  ```

#### Variables
- **Pattern**: `$snake_case`
- Examples:
  ```php
  $header_style
  $dark_header_logo_id
  $modal_storage
  $button_icon
  ```

#### Constants
- **Pattern**: `SCREAMING_SNAKE_CASE`
- Example:
  ```php
  define( '_S_VERSION', '1.0.0' );
  ```

#### Hooks (Actions/Filters)
- **Actions**: `{theme_prefix}_{action_name}`
- **Filters**: `{theme_prefix}_{filter_name}`
- Examples:
  ```php
  add_action( 'after_setup_theme', 'curixus_project_setup' );
  add_filter( 'body_class', 'curixus_project_body_classes' );
  ```

### CSS/SCSS Naming

#### BEM Methodology (Block Element Modifier)
**Pattern**: `.block__element--modifier`

Examples from codebase:
```scss
// Block
.site-header { }
.btn-group { }
.card-tiles { }

// Block with modifier
.site-header--dark { }
.btn--primary { }
.btn--secondary { }

// Element
.site-header__wrap { }
.btn__text { }
.btn__icon { }

// Element with modifier
.btn__icon--left { }
.btn__icon--right { }

// Complex structures
.site-bg__layer--a { }
.site-bg__shape--1 { }
```

#### Utility Classes
- **Pattern**: `utility-name`
- Examples: `.container`, `.small`, `.glass-effect`

#### Background Variant Classes
- **Pattern**: `.bg-variant--{variant-slug}`
- Examples: `.bg-variant--intense-blue-and-purple-middle`, `.bg-variant--yellow`

#### WordPress Block Classes
- Respect WordPress core conventions: `.wp-block-*`, `.has-*`, `.is-style-*`

### JavaScript Naming

#### Variables
- **Pattern**: `camelCase`
- Examples:
  ```javascript
  const bgEl = document.getElementById("site-bg");
  const activeLayer = layers[nextKey];
  const transitionInProgress = false;
  ```

#### Functions
- **Pattern**: `camelCase`
- Examples:
  ```javascript
  function prefersReducedMotion() {}
  function getVariantFromEl(el) {}
  function beginVariantTransition(bgEl, layers, nextVariant) {}
  ```

#### Constants
- **Pattern**: `SCREAMING_SNAKE_CASE`
- Example:
  ```javascript
  const TRANSITION_MS = 900;
  const VARIANTS = [ /* ... */ ];
  ```

#### DOM Selectors
- Use specific, semantic selectors
- Prefer data attributes for JS hooks: `data-fancybox`, `data-bg-variant`, `data-active-layer`

### ACF Field Naming

#### Field Names
- **Pattern**: `snake_case`
- Examples: `header_style`, `button_icon`, `item_title`, `item_description`

#### Field Groups (in block.json)
- Registered via ACF, stored in `acf-json/*.json`
- Group keys: `group_{hash}` (auto-generated by ACF)

#### Block ACF Fields Access
```php
get_field( 'field_name' )              // Top-level field
get_sub_field( 'field_name' )          // Inside repeater/flexible content
the_field( 'field_name' )              // Echo field value
have_rows( 'repeater_name' )           // Check repeater
```

## Code Organization Patterns

### Block Structure

**Standard block anatomy**:
```
blocks/block-name/
├── block.json          # Block registration (ACF mode, supports, etc.)
├── block-render.php    # Server-side rendering template
├── style.scss          # Block-specific styles (compiled to style.css)
└── style.css           # Compiled styles (enqueued via block.json)
```

**block-render.php pattern**:
```php
<?php 
/**
 * Block template file: block-render.php
 *
 * @param   array $block The block settings and attributes.
 * @param   string $content The block inner HTML (empty).
 * @param   bool $is_preview True during AJAX preview.
 * @param   (int|string) $post_id The post ID this block is saved to.
 */

// 1. Generate unique ID
$id = 'block-name-' . $block['id'];
if ( ! empty($block['anchor'] ) ) {
    $id = $block['anchor'];
}

// 2. Build classes
$classes = 'block-base-class';
if ( ! empty( $block['className'] ) ) {
    $classes .= ' ' . $block['className'];
}

// 3. Get wrapper attributes (Gutenberg support)
$wrapper_attributes = get_block_wrapper_attributes([
    'class' => $classes
]);

// 4. Preview image support (optional)
if (isset( $block['data']['preview_image_help'] )  ): 
    // Show screenshot in editor
else:
    // Render actual block content
    // - Use ACF field functions
    // - Echo HTML with proper escaping
endif;
?>
```

### Custom Post Type Pattern

Location: `/inc/post-types/{cpt-name}.php`

```php
<?php
/**
 * Register a {CPT Name} post type.
 *
 * @link http://codex.wordpress.org/Function_Reference/register_post_type
 */

add_action( 'init', '{cpt_name}_cpt' );

if ( ! function_exists( '{cpt_name}_cpt' ) ) :
    function {cpt_name}_cpt() {
        $labels = array(
            'name'               => '{CPT Plural}',
            'singular_name'      => '{CPT Singular}',
            // ... other labels
        );

        $args = array(
            'labels'              => $labels,
            'public'              => true/false,
            'show_ui'             => true,
            'supports'            => array( 'title', 'editor' ),
            'show_in_rest'        => true, // Enable Gutenberg
            // ... other args
        );

        register_post_type( '{cpt_slug}', $args );
    }
endif;
```

### Helper Function Pattern

Location: `/inc/helpers.php`

```php
/**
 * Descriptive function purpose.
 *
 * @param type $param1 Description.
 * @param type $param2 Description.
 * @return type Return value description.
 */
function function_name( $param1, $param2 = 'default' ) {
    // Implementation
    if ($condition) {
        return $value;
    } else {
        echo $output;
    }
}
```

### Walker Pattern

Location: `/inc/walkers.php`

```php
class {Name}_Menu_Walker extends Walker_Nav_Menu {
    // Override start_lvl, end_lvl for submenu wrappers
    // Override start_el, end_el for menu items
    // Use ACF: get_field( 'field_name', $item->ID )
}
```

## SCSS Organization

### Import Order (style.scss)
```scss
@import '_variable';      // 1. Variables & mixins first
@import "_reset";         // 2. Reset/normalize
@import "_components";    // 3. Reusable components
@import "_header";        // 4. Layout sections
@import "_footer";
@import "_bg";            // 5. Special effects
@import "_structure";     // 6. Page structure last
```

### Responsive Breakpoints

Defined in `_variable.scss`:
```scss
@mixin desktop     { @media (max-width: 1350px) { @content; } }
@mixin desktop-sm  { @media (max-width: 1200px) { @content; } }
@mixin tablet      { @media (max-width: 991px)  { @content; } }
@mixin mobile      { @media (max-width: 767px)  { @content; } }
@mixin mobile-sm   { @media (max-width: 575px)  { @content; } }

// Min-width variants
@mixin mf-desktop  { @media (min-width: 992px)  { @content; } }
@mixin mf-tablet   { @media (min-width: 768px)  { @content; } }
```

Usage:
```scss
.element {
    font-size: 24px;
    
    @include tablet {
        font-size: 20px;
    }
    
    @include mobile {
        font-size: 18px;
    }
}
```

### Color Variables

From `_variable.scss`:
```scss
$clr-base: #0A1428;        // Base dark blue
$clr-primary: #FFDD0C;     // Yellow
$clr-coral: #F88673;
$clr-violet: #926FDE;
$clr-blue: #6284C8;
$clr-green: #54F0A3;
$clr-white: #FAFAFA;
$clr-navy: #0A1428;
```

Use variables, not hardcoded hex values.

### Font Handling

```scss
$font-family-primary: 'Montserrat', sans-serif;
$font-family-secondary: 'Bricolage Grotesque', sans-serif;

// Utility mixin for responsive font sizes
@mixin font-rem-min($size, $min-size) {
  $size-rem: px-to-rem($size);
  $min-px: if(unitless($min-size), $min-size * 1px, $min-size);
  font-size: clamp($min-px, $size-rem, $size-rem);
}
```

## WordPress Integration Patterns

### Enqueuing Assets

In `inc/scripts.php`:
```php
function curixus_project_scripts() {
    // CSS - with cache busting via filemtime
    wp_enqueue_style( 
        'handle', 
        get_template_directory_uri() . '/css/file.css', 
        array(),                           // Dependencies
        filemtime(get_template_directory() . '/css/file.css'),
        false                              // Media
    );
    
    // JS - with dependencies and cache busting
    wp_enqueue_script( 
        'handle', 
        get_template_directory_uri() . '/js/file.js', 
        array('jquery'),                   // Dependencies
        filemtime(get_template_directory() . '/js/file.js'),
        true                               // In footer
    );
}
add_action( 'wp_enqueue_scripts', 'curixus_project_scripts' );
```

### Retrieving ACF Options
```php
// From options page
get_field( 'field_name', 'option' );
the_field( 'field_name', 'option' );

// From current post/page
get_field( 'field_name' );

// From specific post
get_field( 'field_name', $post_id );

// From menu item (in walker)
get_field( 'field_name', $item->ID );
```

### Outputting SVG Sprites

Helper function pattern:
```php
sprite_svg( 
    $spriteName,         // Icon ID from sprite
    $svgWidth = '24',    // Width
    $svgHeight = '24',   // Height
    $return = ''         // Return vs echo (default: echo)
);

// Example usage
sprite_svg('icon-arrow', '16', '16');
```

## Rule of Thumb for New Code

### When adding a new feature:

1. **Is it a content block?** 
   → Create in `/blocks/{block-name}/` with block.json + block-render.php

2. **Is it a post type?** 
   → Create in `/inc/post-types/{cpt}.php` and add to `init-cpt.php`

3. **Is it a utility function?** 
   → Add to `/inc/helpers.php`

4. **Is it a template?** 
   → Add to root or `/template-parts/` following WordPress hierarchy

5. **Is it styling?** 
   → Add to appropriate SCSS partial in `/scss/`

6. **Is it interactive JS?** 
   → Add to `/js/` and enqueue in `inc/scripts.php`

7. **Is it ACF configuration?** 
   → Configure in admin (auto-saves to `/acf-json/`)

### Always:
- Use theme prefix for function names
- Use BEM for CSS classes
- Escape output (`esc_html()`, `esc_url()`, `esc_attr()`)
- Sanitize input (when saving data)
- Use WordPress coding standards (spacing, braces, etc.)
- Add PHPDoc comments for functions
- Keep block styles isolated (don't leak to global scope)
